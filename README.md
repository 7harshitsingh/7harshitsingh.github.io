# Harshit Singh — Applied AI Engineer

My single-page portfolio, built with Astro. It brings together my work in applied AI, projects, experience, and writing.

![Preview of Harshit Singh's personal website](public/hero.png)

The screenshot shows local sample articles used to review the Writing card. They are excluded from the published build.

**Website:** [7harshitsingh.github.io](https://7harshitsingh.github.io/)

## Run locally

```bash
npm ci
npx astro dev --background
```

Use `npx astro dev stop` to stop the server. Run `npm run verify` to build the site and check its tests.
